Por que usar Grid Layout na tela inicial? Porque ele organiza os elementos em linhas e colunas (uma grade). Isso é ideal para mostrar várias categorias de roupas lado a lado de forma visual, equilibrada e fácil de clicar.

Qual a vantagem de usar Intents para mudar de tela? A Intent é a ferramenta padrão do Android para abrir uma nova atividade separada. Ela permite mudar da tela de categorias para a de produtos de forma direta, isolando as funções de cada tela.

Quais os benefícios de usar Fragments na tela de detalhes? Os Fragments representam partes modulares da interface. Eles tornam a navegação mais fluida e rápida (sem precisar recriar a tela inteira) e facilitam a reutilização do código e o botão de voltar.

Como o Constraint Layout ajudou na tela de detalhes? Ele permite posicionar elementos (imagem, descrição, botão) ancorando uns aos outros de forma proporcional. Isso cria uma tela flexível e responsiva que se ajusta perfeitamente a qualquer tamanho de celular sem quebrar o layout.
