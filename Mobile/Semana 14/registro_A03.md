O que é uma API e por que ela é útil? Uma API (Interface de Programação de Aplicações) é uma ponte que permite que diferentes sistemas e aplicativos "conversem" e compartilhem dados entre si. Ela é útil porque permite adicionar funções complexas (como mapas ou clima) sem precisar programar tudo do zero.

Quais são os benefícios de integrar uma API em um app de viagens?

Economia de tempo: O desenvolvedor não precisa criar bases de dados complexas de terceiros (como malhas rodoviárias ou satélites de clima).

Dados em tempo real: Garante informações atualizadas de voos, hotéis ou meteorologia.

Experiência rica (UX): Transforma o app em uma plataforma completa onde o usuário resolve tudo em um só lugar.

Escolha de uma API popular e seu valor para o usuário:

API Escolhida: OpenWeatherMap (ou API do Google Maps).

Valor para o usuário: Ao planejar um roteiro para uma praia ou trilha, o usuário vê a previsão do tempo exata daquela localidade direto no app de viagens, evitando surpresas com chuvas e ajudando a escolher as roupas certas.

Desafios de trabalhar com APIs externas e como resolvê-los:

Instabilidade/Quedas da API: Resolve-se criando um sistema de cache local que guarda as últimas informações carregadas caso o serviço fique fora do ar.

Mudanças na API (Manutenção): As APIs mudam suas regras e códigos com o tempo. Resolve-se lendo as documentações e atualizando o app periodicamente.

Custos e Limites de Requisições: APIs famosas cobram se forem muito usadas. Resolve-se otimizando o código para que o app só faça consultas quando for estritamente necessário.
